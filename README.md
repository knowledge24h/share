# share

原创技术内容与行业标准资料的分享仓库。内容以 PDF 为主，按「作品 / 资料 / 标准」三类归档。

---

## 目录结构

```
share/
├── works/        原创作品 —— 自己写、自己做的内容
├── materials/    参考资料 —— 收集整理的素材、外部文档
└── standards/    行业标准 —— 规范原文
```

## 目录说明

| 目录 | 中文 | 存放内容 | 说明 |
| --- | --- | --- | --- |
| `works/` | 作品 | 原创科普、技术拆解、经验总结 | 每篇一个 PDF，文件名即标题 |
| `materials/` | 资料 | 学习素材、外部文章、整理笔记 | 非原创，注明来源 |
| `standards/` | 标准 | 国标、ISO、AUTOSAR 等规范原文 | 仅作学习参考 |

## 仓库约定

- 目录名用小写英文（`works` / `materials` / `standards`），文件名用中文标题，便于检索。
- 一篇内容一个文件，PDF 格式，文件名不加日期前缀。
- 新增内容先归类，再提交：`git add <目录>` → `git commit -m "说明"` → `git push`。

## 使用方式

```bash
# 克隆
git clone https://github.com/knowledge24h/share.git

# 或只下某一份文件（raw 链接）
https://raw.githubusercontent.com/knowledge24h/share/main/works/高效学习法.pdf
```

PDF 在网页上直接点击即可在线预览或下载。
